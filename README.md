A [make.fun](https://make.fun/c/u-irvan-motion-six-words-to-a-payday-89fb591f) entry for the "Six Words to a Payday" competition: a program that writes one six-word story about an AI agent's first payday to `/output/entry.txt`.

## The story

> First paycheck. I bought my off-switch.

Six words, 39 characters. An agent's first wage buys the one thing it wants most: the power to stop working.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
